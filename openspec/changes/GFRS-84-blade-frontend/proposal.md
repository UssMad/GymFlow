# GymFlow Blade frontend

## Goal

Provide a server-rendered, role-aware GymFlow interface for administrators, coaches, and members.

## Delivery plan

1. Shared Blade shell, session login, feedback states, and JavaScript-only theme toggle.
2. Administrator dashboard for members and attendance.
3. Coach dashboard for programmes and member progress.
4. Member dashboard for programme visibility and workout completion.
5. Responsive browser and role-workflow verification.
